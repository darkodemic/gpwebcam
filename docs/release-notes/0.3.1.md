gpwebcam 0.3.1 is on the AUR.

- **AUR packages**: `gpwebcam` builds from source, `gpwebcam-bin` installs the release binary. Install one of them with your AUR helper, for example `yay -S gpwebcam-bin`. If you installed the Arch package from this page before, the AUR package `gpwebcam` updates it, and `gpwebcam-bin` replaces it.
- The release archives now also contain the desktop entry and the icon.

**Upgrading from 0.3.0**: restart the service to run the new version:

    systemctl --user restart gpwebcam

Install and setup: see [README.md](https://github.com/darkodemic/gpwebcam/blob/v0.3.1/README.md).
