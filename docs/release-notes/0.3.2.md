gpwebcam 0.3.2 is on Copr for Fedora.

- **Fedora**: install it from the [Copr repository](https://copr.fedorainfracloud.org/coprs/darko/gpwebcam/), built from source for Fedora 43, 44, 45 and Rawhide on x86_64 and aarch64; dnf keeps it up to date. v4l2loopback and an ffmpeg that decodes H.264 come from RPM Fusion:

      sudo dnf install akmod-v4l2loopback v4l2loopback
      sudo dnf swap ffmpeg-free ffmpeg --allowerasing
      sudo dnf copr enable darko/gpwebcam
      sudo dnf install gpwebcam

  If you installed the `.rpm` from a release page before, run `sudo dnf upgrade gpwebcam` instead of the last line, since `dnf install` leaves an installed package as it is; from then on dnf updates it from Copr.
- **AUR**: building `gpwebcam` from source no longer leaves a read-only Go module cache in `~/go`; the cache stays in the build directory. `gpwebcam-git` builds the newest commit on `main`, for testing what is not released yet.

**Upgrading from 0.3.1**: restart the service to run the new version:

    systemctl --user restart gpwebcam

Install and setup: see [README.md](https://github.com/darkodemic/gpwebcam/blob/v0.3.2/README.md).
